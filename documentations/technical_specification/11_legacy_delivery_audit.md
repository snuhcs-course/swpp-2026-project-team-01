# Legacy contact-delivery assertion audit

Date: 2026-10-09. Source: `5c305d9^:supabase/functions/_shared/modules/delivery/contact_test.ts` (12 named tests).

The current [email contract](../../openspec/specs/email-delivery/spec.md) separates Cloudflare transactional mail from AgentMail conversations. The [rebuild boundary](04_implementation_plan.md#2-execution-rules-and-source-ownership) requires preservation of external resources and migration history but does not require development transcript/link migration. This audit records removed interfaces explicitly; it does not claim binary compatibility with the retired worker.

## Evidence

- [Contact integration](../../tests/integration/contact-delivery.test.ts) exercises the real local PostgreSQL/PostgREST worker with controlled Cloudflare HTTP: frozen content, current authority, duplicate workers, lost responses, expiry and configuration changes.
- [Contact delivery SQL](../../supabase/schemas/43_contact_verification_delivery.sql) owns immutable preparation, one dispatch grant and terminal recovery; [the worker](../../lib/server/email/contact-delivery.ts) implements orchestration.
- [Messaging environment tests](../../tests/providers/messaging-environments.test.ts) verify all current email workers/transports reject non-production managed deployments before database/provider I/O.
- [Booking delivery tests](../../lib/server/email/booking-delivery.test.ts), [recovery integration](../../tests/integration/recovery-delivery.test.ts) and [AgentMail transport tests](../../tests/providers/agentmail-reply-transport.test.ts) cover their separate delivery contracts.

## Historical state and remaining acceptance

A read-only transaction against the explicitly selected production project `mriseqztcwmezvtawnbo` found zero legacy `contact_delivery` jobs, zero old contact verification/recovery outboxes, zero outboxes containing old frozen-envelope keys, and zero old tagged-provider outboxes in sending/uncertain state. The query returned counts only and changed no record. This establishes absence of those records in that project at this inspection, not in another retained project or provider account. Historical SQL/migrations remain intact. Do not route an old uncertain effect through the new worker if one is later discovered; inspect its original provider identity and recovery contract first.

The 12 assertions now have explicit preserved/replacement dispositions. This does not close the wider legacy inventory, authorize an external message, establish a production kill switch, or prove live recipient delivery. Current Cloudflare/contact acceptance and remaining provider/client gates stay with their existing owners in the [implementation plan](04_implementation_plan.md).
