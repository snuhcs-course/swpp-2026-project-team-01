# Retired onboarding API assertion audit

This audit reconciles all thirteen named tests in `5c305d9^:supabase/functions/api/routes/onboarding_test.ts` with the replacement application. It contributes to the [Phase 2 command migration](04_implementation_plan.md#phase-2--build-contracts-identity-schema-and-durable-effects); it does not claim equivalence for the other retired files or live Google/iMessage acceptance.

## Current boundaries

The browser gateway derives authority from verified cookies and rejects cross-origin mutations. [Browser commands](../../lib/server/identity/browser-commands.ts) admit only issued credentials, strict waitlist/redemption inputs and a hashed invitation code. PostgreSQL rechecks current Auth/admission. Calendar selection derives permissions from fresh provider metadata. Photon now uses signed durable webhook ingress and scoped workers; the former standalone bridge and its sequence/resume endpoints are not deployed.

## Initial-binding observation race

This audit's first actual-runtime run received HTTP 409 while opening history immediately after dispatch. The stream implementation rejects a ledger that changes from unbound to its first bound runtime during the read. A [deterministic stream test](../../lib/server/identity/generation-stream.test.ts) reproduces `RECONNECT_REQUIRED`, verifies no mixed-timeline provider read, then reconnects and receives the original user/assistant events with continuous cursors. The settlement fault fixture now observes the atomically bound generation-zero scope and ledger before opening history. It still requires HTTP 200, saved output, process restart and exact no-duplicate outcomes; it does not retry arbitrary 409s or weaken access checks.

Current production behavior is unchanged by this audit. These local fixtures do not prove Google consent, private device delivery, or the remaining retired test inventory. Fresh verification results are recorded in the [evidence ledger](05_rebuild_evidence.md#legacy-onboarding-api-and-initial-binding-acceptance--2026-10-10).
