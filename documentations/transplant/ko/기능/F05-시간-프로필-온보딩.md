# F05 — 시간 프로필: 초안, 세 가지 주제, 대화로 돕기, 직접 확정

## 왜 이렇게 만들었나
- 사람들이 자주 섞어 쓰는 세 가지를 나눴습니다. [문서][코드]
  - **근무시간**: 배경 정보입니다. 이것만으로 시간을 막지 않습니다.
  - **미팅 허용 시간**: 양쪽 모두 미팅 **전체**가 이 안에 들어가야 하는 규칙입니다.
  - **기본 선호**: 순서만 바꿉니다.
- 세 주제를 모두 확인하고 직접 **확정**해야만 적용됩니다. 초안은 예약에 쓰이지 않고, AI의 답이 설정을 끝내 주지도 않습니다. [코드]
- 새 사용자에게 임의의 기본 시간(예: 08–22시)을 열어 주지 않습니다. 프로필이 없으면 예약을 받을 수도 할 수도 없습니다. [코드 주석]
- 대화와 직접 편집은 **같은 초안**을 고칩니다. 직접 편집은 언제나 가능합니다. [코드]
- 프로필은 여러 호스트에게 다시 쓰이므로, 선호에 특정 호스트의 장소나 양식을 넣지 않습니다. [문서][코드]

## 사용자는 이렇게 안내받는다
- **시작 카드**: "근무시간, 미팅을 허용할 시간, 추가 선호를 직접 입력하거나 AI와 대화하며 설정해요. 마지막 확인 전까지는 초안으로만 저장돼요." → **설정 시작**
- **작업 화면** (진행 표시 `직접 설정·대화 → 최종 확인 → 완료`)
  - **직접 설정**
    - "고정 근무시간 없음" 체크, 또는 근무 구간을 입력합니다.
    - **미팅 허용** 구간은 "시간 범위 + 요일 칩" 한 줄 단위로 입력합니다. "평일에 적용", "구간 삭제", "구간 추가"가 있고, 점심은 구간을 나눠 비우게 안내합니다. 하루의 끝은 24:00입니다.
    - **기본 선호**: 선호 요일 / 선호 시작 시간 / 미팅 방식 / 미팅 사이 여유. 항목마다 "선호 없음 · 가능하면 · 중요해요"를 고릅니다.
    - **주제별 확인** 체크 세 개: "근무시간을 확인했어요 / 미팅 허용시간을 확인했어요 / 기본 선호를 확인했어요 (선호 없음 포함)", 진행은 n/3으로 보입니다.
  - **대화**
    - 제목 "말로 설명해도 좋아요"
    - 예시 문구 "평일 10시부터 5시까지 미팅 괜찮고, 점심 12–1시는 비워 주세요."
    - 상대 이름은 "설정 도우미"
  - **주간표**
    - 월요일부터, 하루 24시간 막대로 보여줍니다. 위의 얇은 회색이 근무, 아래의 청록이 미팅 허용입니다.
    - "외부 일정의 빈 시간 조회 결과는 아니에요"라고 선을 긋습니다.
  - **아래 고정 바**: 저장됨 / 미저장 변경이 있어요 / 저장 중 · "주제 확인 n/3" · **최종 확인**
- **최종 확인 화면**
  - 요약표와 주간표를 보여주고 "확정하기 전까지는 현재 적용 중인 프로필이 바뀌지 않아요"라고 안내합니다.
  - 버튼: 돌아가서 수정 / **이 설정으로 확정**
- **완료** "프로필 설정을 완료했어요." → 내 프로필 보기 / 예약하기
- **내 시간 프로필** 화면은 "적용 중인 시간 프로필 · 버전 N"과 주간표를 먼저 보여주고, 그 아래에서 같은 편집기로 고칩니다.

## 지켜지는 규칙
- **구간 규칙**: 같은 날 안에서만 쓰고, 시작이 끝보다 빨라야 합니다. 겹치는 구간은 자동으로 합칩니다.
- **검증**
  - "고정 근무"를 골랐다면 근무 구간이 하나 이상 있어야 합니다.
  - 선호 요일·시간이 미팅 허용 시간과 하나도 겹치지 않으면 확정할 수 없습니다.
  - 허용 시간을 비운 채 확정할 수는 있지만, 그러면 "예약 불가" 상태가 됩니다.
- **자동 저장**
  - 입력하고 0.5초 뒤, 올바른 입력일 때만 저장합니다.
  - 저장하지 않은 채 나가려 하면 경고합니다.
  - 다른 화면과 충돌하면 비교해서 고르게 합니다.
- **확정**하면 새 버전이 쌓이고(이전 버전은 남음), 그 순간부터 예약 계산에 쓰입니다.
- **대화 한 번**
  - "안녕" 같은 인사만으로는 아무것도 바꾸지 않습니다.
  - AI는 사용자가 **명시한 것만** 설정 변경으로 뽑습니다. 근무시간을 추측하거나 과거 일정으로 허락해서는 안 됩니다.
  - 실패하면 값은 그대로 두고 "해석하지 못했어요"를 표시합니다.
  - **답 문장은 AI가 쓰지 않습니다.** "초안에 반영했어요…" 뒤에, 아직 확인하지 않은 다음 주제(근무 → 허용 시간 → 선호)를 묻는 정해진 질문이 붙습니다. 분석에 대한 질문이면 F04의 답을 붙입니다.

## 이식할 때
- 핵심: 세 가지 구분, 세 주제 확인, "확정된 버전만 적용" 규칙
- UI: 요일 칩 구간 편집기와 주간표는 독립 컴포넌트라 그대로 가져갈 수 있습니다.
- 대화는 선택 사항입니다. 빼더라도 직접 편집과 주제 확인 체크만으로 제품은 완결됩니다.
