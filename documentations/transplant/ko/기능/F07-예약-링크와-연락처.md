# F07 — 예약 링크와 연락처 (연결된 사람에게만 예약)

## 왜 이렇게 만들었나
- 예약은 초대에서 시작합니다. 누구나 개인 링크가 있고, 그 링크를 열거나 붙여 넣으면 두 사람이 **서로 연락처**가 됩니다. 연락처에게만 예약할 수 있고, 실제·데모 모드 모두 같습니다. [커밋]
- 링크는 전달할 수는 있어도 추측할 수는 없습니다. **새 링크로 바꾸면** 이전 링크는 막히지만, 이미 맺은 연락처는 그대로입니다. [코드]
- 로그인을 거쳐도 링크가 이어집니다. 로그인 전에 열었다면 로그인한 뒤 같은 링크로 돌아옵니다. [코드]

## 사용자는 이렇게 안내받는다
- **호스트 설정 › 내 예약 링크**
  - "이 링크를 받은 사람이 열면 서로 연락처에 추가되고 나에게 미팅을 요청할 수 있어요."
  - **링크 복사**: 실패하면 직접 선택하라고 안내합니다.
  - **새 링크로 바꾸기**: "지금 링크는 더 이상 열리지 않아요. 이미 추가된 연락처는 그대로예요. 바꿀까요?" 확인을 거칩니다.
- **링크를 연 사람의 화면** "○○님이 미팅 예약 링크를 보냈어요"
  - 잘못됐거나 바뀐 링크: "링크를 열 수 없어요…" + 처음으로
  - 내 링크: "미팅을 요청받고 싶은 사람에게 보내 주세요." + 호스트 설정으로
  - 로그인함: **연락처에 추가하고 예약하기** → 바로 예약 화면
  - 로그인 안 함: 로그인 버튼 → 로그인 후 같은 링크로 복귀
- **예약하기 화면 위쪽**
  - "상대에게 받은 예약 링크를 열거나 여기에 붙여 넣으면 서로 연락처에 추가돼요."
  - 입력칸과 **연락처에 추가** 버튼. 링크 전체든 코드만이든 받아 줍니다.
- 연락처가 없으면 "아직 연락처가 없어요 · 예약 링크로 추가한 사람이 여기에 나타나요."

## 지켜지는 규칙
- 링크 코드는 처음 볼 때 만듭니다.
- 연락처는 양방향으로 한 번에 맺어지고, 중복되지 않습니다.
- 연락처가 아닌 사람의 예약 화면은 404이고, 서버에서도 탐색 시작을 거부합니다.

## 이식할 때
예약 엔진과 무관해서 사용자가 있는 어떤 앱에도 넣을 수 있습니다. 대상이 "누구나 나를 예약할 수 있는" Calendly식이라면 연락처 제한은 빼고, 링크 화면의 상태 구성만 가져가면 됩니다.
