# Tasks

Group 1 records the team's decisions and group 2 lays the schema; both are serial. Groups 3 to 6 are the plan's Phase 3 lanes A to D and can run in parallel against the merged schema; Lane C's engine (5.1) can start before the schema because it is pure domain code. Group 7 is the join and group 8 the release.

Before each group, read the [Phase 3 reference repository files](../../../documentations/technical_specification/06_implementation_plan.md#5-reference-repositories-per-phase) and name the files and revisions followed in the pull request. The proposal's [coverage table](proposal.md#modified-capabilities) lists which scenarios this change closes and which stay deferred. Evidence goes to the [acceptance record](../../../documentations/technical_specification/07_acceptance_record.md) with command, date, revision and environment.
