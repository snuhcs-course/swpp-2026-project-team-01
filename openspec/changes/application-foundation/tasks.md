# Tasks

Group 1 is serial. Task 2.1–2.3, the schema baseline and its CI job, merges next and alone. After that, the rest of groups 2, 3 and 4 run in parallel as the plan's Phase 1 lanes, and any lane that adds tables starts its migration from the merged baseline. Group 5 is the join.

Read the [reference repository files for Phase 1](../../../documentations/technical_specification/06_implementation_plan.md#5-reference-repositories-per-phase) before starting each group, and name the files and revisions followed in the pull request. The proposal's [coverage table](proposal.md#modified-capabilities) lists which spec scenarios each group closes and which are deferred.
