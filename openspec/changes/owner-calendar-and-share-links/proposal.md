# Proposal

## Why

로그인 후 실제 캘린더와 추천 가능한 시간을 함께 볼 수 없고, 생성한 요청 링크의 용도·공개 시간·요청자를 확인하거나 상태를 관리할 수 없다. 사용자가 자신의 시간을 이해하고 링크를 관리할 수 있도록 소유자 홈을 확장한다.

## What Changes

- Google Calendar와 유사한 주간 시간표에 실제 기본 캘린더 일정과 규칙으로 계산한 빈 시간을 함께 표시한다.
- 적용 중인 조건(내일부터 14일, 평일 09:00–20:00, 서울 시간, 이동 여유)을 읽기 전용으로 공개한다.
- 이름을 입력해 요청 링크를 만들고, 생성 시의 공개 시간대를 저장한다.
- 링크 상세에서 공개 시간과 요청자를 확인하고, 주소 복사·일시 닫기·다시 열기·삭제를 지원한다.
- 삭제는 새 요청을 막되 기존 받은 요청은 보존한다.
- 소유자 화면 표시를 위해 본인 일정 제목을 조회한다. 상대방에게 제목을 공개하거나 DB에 저장하지 않는다.
- 실제 AI 모델 연결, 조건 편집, 가능 시간 블록 편집, 받은 요청 수락 및 Google 일정 생성은 포함하지 않는다.

## Capabilities

### New Capabilities

- `owner-calendar-view`: 실제 캘린더와 미팅 가능 시간을 함께 보여주는 소유자 홈.
- `request-link-management`: 이름·공개 시간·요청자·상태를 관리하는 요청 링크.

### Modified Capabilities

없음. 기존 MVP의 활성 변경 문서에는 소유자 제목 조회 예외와 새 변경 참조를 반영한다.

## Impact

Next.js 소유자 화면, Calendar 조회, 요청 링크 API, 요청 시 링크 유효성 확인 및 Supabase share_links 스키마가 변경된다. Google OAuth 권한은 기존 읽기 전용 범위를 사용한다. API 키나 새 AI 서비스는 필요하지 않다. 로컬 앱과 기존 Supabase 프로젝트를 사용한다.
