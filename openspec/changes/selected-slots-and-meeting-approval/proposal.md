# Proposal

## Why
호스트가 공개 범위와 미팅 길이를 직접 정하고 특정 후보만 공개하며, 들어온 요청을 바로 확정할 수 있어야 한다.

## What Changes
- 날짜·요일·일중 시간과 미팅 길이를 지정하고 추천 후보 최대 5개 중 2개 이상 선택해 링크 생성.
- 링크 상세에 선택한 시간의 작은 주간 시간표 제공.
- 요청자는 호스트가 정한 길이를 사용하며, 양쪽 캘린더에 맞는 선택 후보를 계산.
- 호스트가 요청의 후보 하나를 선택해 수락하면 Google 일정 등록 및 참석자 초대 알림 발송.
- 호스트 쓰기 권한 추가 동의와 중복 등록 방지·실패 복구 지원.

## Capabilities
### New Capabilities
- `selected-slot-links`: 호스트의 공개 범위·길이·후보 선택과 주간 시각화.
- `meeting-approval`: 소유자의 수락, Google 등록, 요청자 초대.
### Modified Capabilities
이전 활성 변경의 동작을 대체하며 해당 문서에 후속 변경을 안내한다.

## Impact
Next.js 링크 생성/상세, 요청 폼/API, OAuth, Supabase 스키마 및 서버 Calendar 쓰기 호출이 변경된다. 로컬 웹 앱과 기존 Supabase 프로젝트를 계속 사용한다. 실제 초대는 사용자가 수락 버튼을 누를 때만 보낸다.
