# Find Me a Time — 시각 디자인

## 범위와 책임

이 문서는 Thyme 로고 탐색과 [식물 참고 보드](https://kr.pinterest.com/callmejustdodo/thyme/)에서 도출한 시각 방향을 정의합니다. 이후 브랜드와 웹 스타일링의 기준이 됩니다. 아래의 정확한 토큰은 그 분위기에서 도출한 구현 선택이며, 참고 이미지에서 추출한 색상이 아닙니다.

**Find Me a Time**은 제품이고, **Thyme**은 일정 조율 어시스턴트입니다. [디자인 원칙](documentations/03_design_principles.md)은 상호작용 방향을 담당합니다. [원페이저](documentations/01_one_pager.md), [PRD](documentations/02_product_requirements.md), [기능 명세](openspec/specs/)는 제품 범위와 동작을 담당합니다. 시각 스타일은 이들이 정한 동의, 개인정보 보호, 예약 규칙을 지켜야 합니다.

선택된 로고와 잘리지 않은 참고 이미지는 문서 자산으로 보관합니다. 컴포넌트 구조, 메시지·작성창 상호작용, 반응형 마감은 [참고 저장소](documentations/technical_specification/02_frontend_architecture.md#reference-repositories)의 Vercel chatbot과 eve 채팅 템플릿을 연구해 이 팔레트에 맞게 가져옵니다. Phase 1 테마는 `apps/web/app/globals.css`([제안된 구현 매핑](#proposed-implementation-mapping)에 설명한 대로 토큰을 shadcn 역할에 매핑), 루트 레이아웃의 글꼴, 공유 `components/ui`와 `components/chat` 레시피에 있습니다. [알려진 공백](#known-gaps)을 참고하십시오.

## 분위기

차분하고 사려 깊으며, 식물적이고, 조용히 편집적인 느낌입니다. 섬세한 식물 형태를 읽기 쉬운 제품 UI, 따뜻한 종이 질감, 넉넉한 여백과 어울리게 씁니다. 신중하게 쓴 좋은 문구지처럼 환영받는 느낌, 촉각적인 느낌, 쉽게 실행할 수 있는 느낌을 주어야 합니다.

절제된 올리브 색, 따뜻한 아이보리, 자연스러운 짙은 잉크, 가는 선, 절제된 세리프 제목을 사용합니다. 일러스트는 브랜드 순간과 빈 상태에 집중시킵니다. 활성 대화와 일정 검토에서는 시각적 명확성이 우선입니다.

## 로고

![Thyme 식물 시계 로고](documentations/assets/thyme-logo.png)

선택된 로고 자산은 [documentations/assets/thyme-logo.png](documentations/assets/thyme-logo.png)이며, 원본 생성 이미지를 380 × 380px 정사각형으로 자른 것입니다. 원본 픽셀과 아이보리 배경을 유지하며, 마크를 늘이지 않습니다. 출처 확인을 위해 [잘리지 않은 참고 이미지](documentations/assets/thyme-logo-concept.png)도 남겨 둡니다. 앞으로 애플리케이션에서 이 자산의 경로와 제공 방식은 구현과 시각 검증이 필요합니다.

마크는 열린 시계 원의 왼쪽과 아래쪽을 따라 굽는 타임 줄기입니다. 바늘은 **10:10**을 가리킵니다. 짧은 시침은 왼쪽 위를, 긴 분침은 오른쪽 위를 향합니다. 가늘고 유기적인 줄기, 작은 잎, 열린 호, 절제된 중심 축을 그대로 유지합니다.

- 심볼에는 글자가 없습니다. 제품명은 별도의 인터페이스 텍스트로 표시합니다.
- 아이보리 바탕에 올리브 색을 씁니다. 대비나 인쇄상 필요하면 단색 짙은 잉크 버전을 사용합니다.
- 보이는 마크 너비의 최소 5분의 1만큼 모든 방향에 여백을 둡니다. 이 여백은 레이아웃에 직접 넣습니다. 저장된 로고 자산은 여백 없이 촘촘히 잘려 있습니다.
- UI에서 전체 식물 마크는 최소 48px 너비를 유지합니다. 16–32px에서는 잎을 줄이고 획을 굵게 한 단순화 버전을 사용합니다. 이 자산은 사용 전에 따로 준비하고 검증합니다.
- 마크를 늘이거나 회전하지 않습니다. 그림자를 넣지 않습니다. 장식 배지로 감싸지 않습니다. 바늘을 로딩 표시처럼 애니메이션하지 않습니다.
- 로고가 홈 링크의 유일한 내용이면, 링크에 접근 가능한 제품명 레이블을 붙입니다. 주변 텍스트가 이미 제품을 식별하면 이미지는 장식으로 취급합니다.

선택된 PNG는 불투명한 아이보리 배경과 래스터 디테일을 가지며, 투명하거나 벡터인 자산이 아닙니다. 표시할 때 가로세로 비율을 유지합니다. 무드보드의 로고를 복사하지 않습니다.

앱 전체에서 의미 기반 테마 역할을 사용합니다. 식물 올리브는 일러스트와 경계선에 씁니다. 배경 위에서 3.53:1인 대비는 일반적인 작은 텍스트에 부족합니다. 장식용 구분선은 대비가 1.36:1에 불과하므로, 상호작용 컨트롤의 유일한 경계가 될 수 없습니다.

단색 토큰 쌍의 대비는 잉크/캔버스 11.71:1, 보조 잉크/캔버스 5.49:1, 기본 버튼 위 텍스트/기본색 7.33:1입니다. 오류, 주의, 성공 텍스트는 각각 캔버스 위에서 6:1을 넘습니다. 질감, 상태 채우기, 투명도를 추가한 뒤에는 실제 조합을 다시 검증합니다.

## 종이 재질과 질감

주 배경은 **따뜻한 무광 비코팅 종이**처럼 보여야 하며, 미세하고 불규칙한 결을 가져야 합니다. 캔버스 토큰에서 시작해 중립적인 질감 레이어를 2.5% 불투명도로 더합니다. 상한은 4%입니다. 질감은 가까이 볼 때 드러나야 하며, 읽기를 방해하지 않아야 합니다.

- 작고 이음새가 없으며 로컬에서 제공되는 질감 타일 하나를 사용합니다. 화면 너비와 관계없이 스케일을 일정하게 유지하여, 큰 얼룩이 아니라 미세한 섬유처럼 보이게 합니다.
- 텍스트, 입력란, 버튼, 대화 메시지, 제안 세부 정보, 캘린더, 오버레이는 깨끗한 표면 위에 둡니다. 결은 주로 페이지의 주변 여백과 넉넉한 브랜드 영역에서 보여줍니다.
- 페이지 컨테이너나 그 콘텐츠에 투명도를 적용하지 않습니다. 결은 `pointer-events: none`을 가진 별도의 장식 배경 레이어에 두며, 모든 상호작용 콘텐츠 뒤에 놓습니다.
- 질감은 재질감을 암시하는 용도로만 씁니다. 얼룩, 주름, 찢긴 가장자리, 줄 친 선, 강한 노이즈, 누런 양피지 느낌, 접힌 종이처럼 보이는 가짜 컨트롤을 피합니다.
- 질감은 정적으로 유지합니다. 움직이는 결, 시차, 스크롤에 따른 재질 효과를 쓰지 않습니다.
- 질감이 로드되는 동안에는 단색 대체 배경을 유지합니다. 강제 색상 모드에서는 질감을 빼고 시스템 색상을 따릅니다. 인쇄에서도 질감을 뺍니다.
- 모바일과 데스크톱 너비, 200% 확대에서 타일의 이음새가 보이는지 확인합니다. 가장 어두운 질감 영역에서 텍스트와 포커스 대비를 다시 확인합니다.

로고 참고 이미지의 아이보리 배경은 팔레트를 전달합니다. 앞으로 만들 원본 종이 타일은 고정된 미세 결 스케일과 2.5% 불투명도를 사용합니다. 로고 이미지를 타일처럼 반복하거나 페이지 배경으로 쓰지 않습니다.

## 타이포그래피

편집용 디스플레이 제목에는 **Merriweather**, 본문과 인터페이스 텍스트에는 **Geist**, 필요한 기술 식별자에는 **Geist Mono**를 씁니다. 시스템 대체 글꼴을 유지합니다. 앱은 이 글꼴을 시스템 대체 글꼴과 함께 로드하고, 본문에는 Geist를 사용해야 합니다.

| 역할 | 크기 | 굵기 | 줄 높이 | 용도 |
| --- | --- | --- | --- | --- |
| 디스플레이 | `clamp(40px, 6vw, 72px)` | 400 | 1.12 | 랜딩 페이지 헤드라인 |
| 페이지 제목 | `clamp(28px, 4vw, 40px)` | 400 | 1.2 | 접근 및 개요 페이지 |
| 섹션 제목 | 22–28px | 400 | 1.3 | 편집형 섹션 소개 |
| 컴포넌트 제목 | 16–18px | 600 | 1.4 | 산세리프 카드와 대화상자 제목 |
| 본문과 대화 | 16px | 400 | 1.65 | 문단과 메시지 |
| 컨트롤 | 14–16px | 500 | 1.4 | 버튼, 내비게이션, 레이블 |
| 보조 텍스트 | 14px | 400 | 1.5 | 설명과 메타데이터 |
| 압축 메타데이터 | 12px | 500 | 1.5 | 짧은 시간 표시와 부가 레이블 |

디스플레이 글자 간격은 -0.02em에서 0 사이로 유지하고, 본문은 기본 글자 간격을 씁니다. 스크립트체 글꼴, 글자 간격을 크게 벌린 문단, 조밀한 컨트롤 안의 장식 세리프 텍스트를 피합니다. 입력란과 텍스트 영역은 최소 16px 텍스트를 사용합니다. 관련이 있으면 날짜를 명시적인 시간대와 함께 표시하고, 정렬된 시간에는 고정폭 숫자를 사용합니다.

## 레이아웃과 간격

4px 간격 기반과 프런트매터의 간격 척도를 사용합니다. 기본 간격은 컨트롤 안에서 8–12px, 섹션 안에서 16–24px, 섹션 사이에서 32–64px입니다. 마케팅 섹션은 콘텐츠가 필요로 할 때 64–96px을 쓸 수 있습니다.

마케팅 콘텐츠는 약 1120px 안에 가운데 맞춥니다. 대화형 읽기 열은 약 680–720px, 간결한 폼은 약 420–480px, 산문은 한 줄당 약 60–70자로 유지합니다. 모바일 여백은 16–24px, 데스크톱 여백은 32–64px을 씁니다. 장식 이미지를 위해 공간을 남기지 말고, 콘텐츠에 맞춰 레이아웃이 반응하게 합니다.

대화 호스트 화면은 현재 주고받는 내용과 작성창에 쉽게 닿도록 유지해야 합니다. 일정 제안은 명확한 순서를 가집니다. 회의 맥락, 제안된 날짜와 시간대, 길이, 장소, 현재 상태, 허용된 다음 액션 순입니다. 스타일이 각 행위자가 접근할 수 있는 세부 정보나 액션을 바꾸지는 않습니다.

## 형태, 선, 고도감

작은 요소에는 4px 모서리 반경, 버튼과 입력란에는 8px, 카드와 작성창 표면에는 12px, 대화상자에는 16px을 씁니다. 완전히 둥근 형태는 아바타와 짧은 상태 배지에만 씁니다.

기본은 평평한 표면과 1px 선입니다. 질감은 종이의 재질감을 제공하므로, 일반 카드에 그림자가 필요하지 않습니다. 떠 있는 메뉴와 대화상자에는 `0 8px 24px rgb(48 54 43 / 0.08)` 같은 절제된 그림자를 씁니다. 광택 하이라이트, 유리 효과, 종이를 겹친 것처럼 보이는 시뮬레이션을 추가하지 않습니다.

| 텍스트 링크 | 액션 올리브, 밑줄 또는 지속적인 비색상 신호 |
| 입력란 | 매끄러운 표면, 올리브 필드 경계, 항상 보이는 레이블, 16px 텍스트, 인라인 검증 |
| 작성창 | 매끄러운 표면, 12px 반경, 절제된 테두리, 명확한 전송과 대기 상태 |
| 어시스턴트 메시지 | 열린 읽기 레이아웃, 짙은 텍스트, Thyme 발화자 레이블, 장식적인 종이 효과 없음 |
| 사용자 메시지 | 미묘한 표면 구분과 행위자 레이블, 긴 콘텐츠도 읽기 쉽게 유지 |
| 제안 카드 | 간결한 제목과 구조화된 세부 정보, 눈에 띄는 현재 액션, 보이는 상태 텍스트 |
| 대화 카드 | 한 번에 하나만 열림, 최신 메시지 뒤에 표시; 답변이 끝나면 한 줄 영수증(값, 출처 배지, **편집**)으로 접혀 기록에 남음; 질문 하나는 16px 제목으로, 제안된 값과 출처 배지, 짧은 이유 하나, 이어서 액션; 가로 16px, 세로 12px 패딩; 작성창 위에서 휴대폰 뷰포트에 들어맞으며, 긴 편집기는 카드 안에서 스크롤됨([한 번에 하나만](documentations/03_design_principles.md#4-one-thing-to-think-about-at-once)) |
| 상태 배지 | 짧고 명확한 상태 레이블, 절제된 색조, 선택적 아이콘. 색상만으로 전달하지 않음 |
| 빈 상태 | 명확한 설명 하나와 다음 액션 하나, 선택적으로 작은 식물 일러스트 |
| 대화상자 | 매끄러운 종이 표면, 접근 가능한 제목, 명확한 액션 순서, 유지되는 포커스 동작 |

새 의존성을 설정한 뒤에는 선택된 shadcn 및 대화 컴포넌트 방향을 사용합니다. 그 변형을 우선 쓰고, 호출 지점마다 색상과 타이포그래피를 덮어쓰지 않도록 공유 레시피를 갱신합니다. 정보 밀도는 각 작업에 맞게 유지합니다. 여백이 넓은 랜딩 페이지 때문에 캘린더 검토가 번거로워지면 안 됩니다.

## 어조와 움직임

따뜻하고 직접적인 문구를 씁니다. 예를 들면 “시간을 찾아볼까요?”, “이 제안을 검토하세요”, “캘린더가 연결되었습니다” 같은 표현입니다. Thyme은 어시스턴트 정체성으로, Find Me a Time은 제품 정체성으로 보여줍니다. 대기 중, 제안됨, 승인됨, 예약됨 상태를 정확히 설명하고, 서비스가 확인한 뒤에만 성공을 알립니다.

색상과 불투명도 전환은 120–180ms의 짧은 애니메이션을 사용합니다. 메시지가 스트리밍되는 동안 안정적인 읽기 위치를 유지합니다. 동작 감소 설정을 존중하며, 장식용 식물 요소와 시계 바늘은 움직이지 않게 합니다.

## 반응형과 접근성 동작

- 주요 컨트롤과 아이콘 액션에는 최소 44px 터치 대상을 씁니다. 아이콘만 있는 버튼에는 접근 가능한 이름을 붙입니다.
- 2px 실선 포커스 윤곽을 3px 오프셋과 함께 항상 보이게 합니다. 종이, 깨끗한 표면, 인접 컨트롤 위에서도 분명해야 합니다.
- 일반 텍스트는 4.5:1, 큰 텍스트와 필수 컨트롤 경계는 3:1 대비를 목표로 합니다. 질감 영역을 포함해 렌더링된 상태를 검증합니다.
- 텍스트가 줄바꿈되고, 레이블이 늘어나고, 긴 이름과 링크가 줄바꿈될 수 있게 합니다. 320px과 200% 확대에서 페이지의 가로 스크롤을 피합니다.
- 작은 화면에서는 제안 세부 정보와 액션을 쌓아 배치합니다. 시간대 레이블은 계속 보이게 합니다. 작성창 주변의 모바일 키보드와 안전 영역 여백을 고려합니다.
- 상태 색상은 텍스트와 함께 씁니다. 의미 있는 제목과 필드 레이블을 유지합니다. 관련된 대기 상태와 오류 상태는 읽기를 방해하지 않으면서 알립니다.

## 허용 사항과 금지 사항

**허용:** 미세한 종이 결, 식물 선화, 따뜻한 중간색, 더 짙은 올리브 액션, 여유 있는 읽기 열, 명확한 일정 상태를 사용합니다.

**금지:** 세부적인 작업 콘텐츠 뒤에 질감을 두는 것, 작은 텍스트에 연한 식물 색을 쓰는 것, 모든 컨트롤에 잎을 흩뿌리는 것, 오류를 숨기기 위해 단색 팔레트를 쓰는 것, 시각적 차분함으로 명확한 확인을 대체하는 것.

## 제안된 구현 매핑

기반 작업이 만들어지면 공유 스타일시트, 루트 레이아웃, 컴포넌트 레시피를 구현의 기준으로 삼습니다. 선택된 Next.js, Tailwind/shadcn, 접근 가능한 대화 UI 방향을 유지하며, 의존성 버전과 프리셋은 기반 작업에서 정합니다.

캔버스와 잉크는 background와 foreground에, 표면은 card와 popover에, 액션 올리브와 아이보리는 primary 역할에, 부드러운 워시는 secondary, muted, accent에, 장식 선은 border에, 필드 경계는 input에, 포커스는 ring에 매핑합니다. 추가 hover, 누름, 주의, 성공 역할은 명시적으로 둡니다. 반경 척도는 의도적으로 적용하고, 글꼴 계열을 바꾸기 전에 글꼴을 먼저 로드합니다. 장식용 종이 레이어는 깨끗한 컨트롤과 콘텐츠에서 분리해 둡니다.

## 반복 작업 가이드

디자인을 적용할 때는 캔버스, 종이 레이어, 텍스트 대비, 타이포그래피부터 시작합니다. 그다음 공유 컨트롤, 대화 표면, 제안 카드를 갱신합니다. 마지막으로 브랜드 자산과 반응형 다듬기를 마칩니다.

랜딩 페이지, 긴 메시지가 있는 대화, 호스트 승인을 기다리는 제안, 검증 오류, 키보드 포커스가 있는 대화상자를 검토합니다. 375px과 1280px 너비, 200% 확대, 동작 감소, 강제 색상을 확인합니다. 변경된 코드와 관련된 앱 검사를 실행합니다. 문서 검증만으로는 렌더링된 테마를 검증할 수 없습니다.

## 알려진 공백

- 밝은 테마, 글꼴, 종이 레이어, 포커스 윤곽선, 동작 줄이기 처리가 구현되었습니다. `apps/web/app/theme.test.ts`는 가장 어두운 질감 영역 위의 텍스트를 포함해 문서화된 대비 쌍을 검사하고, `tests/e2e/theme.test.ts`는 렌더링된 종이 레이어, 인쇄와 강제 색상에서의 생략, 글꼴, 포커스 윤곽선, 동작 줄이기를 검사합니다. 제안 카드, 대화상자, 상태 배지는 만들어질 때 레시피를 갖춥니다.
- 잘린 PNG와 잘리지 않은 원본은 문서 자산 아래에 보관합니다. 벡터 원본, 작은 크기용 단순화 마크, 출력 변형은 아직 준비하고 검증해야 합니다.
- 종이 타일은 [documentations/assets/paper-grain.svg](documentations/assets/paper-grain.svg)이며 `apps/web/public/paper-grain.svg`로 제공됩니다. 불투명도 2.5%의 128px 이음새 없는 프랙탈 노이즈 타일이며, 인쇄와 강제 색상에서는 비활성화됩니다. 실제 하드웨어 디스플레이에서 200% 확대로 이음새를 눈으로 확인하는 검사는 아직 남아 있습니다.
- 식물 어두운 테마에는 별도의 대비와 시각 검토가 필요합니다. 질감을 자동으로 반전하지 않습니다.
- 무드보드 참고 이미지는 시각 방향에만 쓰입니다. 독자적인 아트워크와 타이포그래피를 사용합니다. 참고 이미지는 원본 브랜드 자산을 재사용할 권리를 부여하지 않습니다.
