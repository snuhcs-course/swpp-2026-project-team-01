## S0 공통 헤더
- 사용자 전환 드롭다운(시드 사용자)
- 메뉴: 예약하기(S4) · 내 캘린더(S1) · 설정(S2/S3) · 내 요청(S7) · 받은 요청함(S8, pending 개수 배지)

## S1 내 캘린더
- 오늘부터 60일, 주 단위로 넘겨 본다.
- 일정 블록: 제목, 시간, 장소 배지(회사 / 장소명 / 온라인 / 없음). 수락된 미팅은 다른 색으로 구분한다.
- 가능 시간 규칙 밖 시간은 회색 음영으로 표시한다.
- 일정 추가(제목, 날짜, 시작/끝, 장소) · 삭제

## S2 가능 시간 규칙
- 요일 7행. 각 행에 켜기/끄기 + 시작/끝 시각을 둔다. 기본값은 08:00–22:00.
- 저장

## S3 호스트 설정
- 장소 목록(종류: 회사 근처 / 특정 장소 / 온라인, 이름) 추가·수정·삭제
- 미팅 양식 목록(이름, 길이: 분 단위로 호스트가 직접 입력) 추가·수정·삭제
- 둘 중 하나라도 비어 있으면 "현재 예약을 받을 수 없음" 경고를 띄운다.

## S4 호스트 목록
- 카드: 이름, 장소 종류 배지, 미팅 양식 목록
- 장소나 양식이 없는 호스트는 "예약 불가"로 표시하고 비활성화한다.
- 자기 자신은 목록에서 제외한다.

## S5 예약 대화
- 상단: 호스트 이름 · 현재 조건에 맞는 슬롯 수
- **칩 바**: 현재 필터. 칩마다 세기(반드시/강/약)를 표시하고 × 버튼으로 삭제한다.
- 대화 영역: 사용자와 AI 말풍선
- **후보 버튼 카드**(AI 말풍선 아래, 최대 3개): `10월 7일(화) 14:00 · 회사 근처 · 30분 커피챗`
- 입력창 + 전송
- 상태
  - LLM 응답 대기: 로딩 표시
  - LLM 장애(서비스에 닿지 못함): 배너 "AI 응답을 받지 못했어요. 잠시 후 다시 시도하거나 칩으로 직접 조정할 수 있어요"
  - 해석 실패(모델 출력 사용 불가): 배너 "AI가 말씀을 해석하지 못했어요. 칩으로 직접 조정하거나 다시 말씀해 주세요"
  - 후보 0개: AI가 완화 안내(US-25)

## S6 요청 폼 (모달)
- 고정 정보: 일시, 장소, 양식, 호스트
- 메시지 입력(필수, 500자, 글자 수 표시)
- 전송 / 취소
- 서버 검증 실패 시: 모달 안에 이유를 표시하고 "대화로 돌아가기"를 둔다.

## S7 내 요청
- 목록: 호스트, 일시·장소·양식, 상태(pending / accepted / declined / 만료)
- pending 요청에 "철회" 버튼

## S8 받은 요청함
- 탭: pending / accepted / declined
- pending은 **같은 시간대끼리 묶어서** 보여준다. 묶음 안의 각 요청에 클라이언트, 메시지, 수락/거절 버튼이 있다.
- 수락 시 확인 문구: "겹치는 요청 N건은 자동 거절됩니다"
- 재검증에 실패하면 이유를 표시하고 수락을 막는다.
- 시작 시각이 지난 pending은 "만료"로 표시하고 버튼을 비활성화한다.
