# 01 — 전체 유저 여정

## 처음 들어올 때

- **로그인 화면** "나에게 맞는 미팅 시간"
  - 오른쪽에 세 단계를 미리 보여줍니다. ① Calendar 연결(선택) ② 시간 프로필 ③ AI와 예약
  - 의도: "연결은 선택이고, 확정은 내가 한다"는 기대를 처음부터 심어 줍니다. [코드]
- **로그인 후** 프로필이 없으면 **Calendar 연결** 화면으로, 있으면 **예약하기**로 보냅니다. 처음 온 사람은 시간 설정부터 하게 합니다. [코드 주석]
- **예약 링크**(`/invite/…`)로 들어오면
  - 로그인한 상태: "연락처에 추가하고 예약하기" 한 번이면 바로 그 사람과의 예약 화면이 열립니다.
  - 로그인 전: 로그인한 뒤 같은 링크로 돌아옵니다.
- **상단 메뉴**는 세 묶음입니다.
  - 예약: 예약하기 · 내 요청 · 받은 요청함(대기 건수 배지)
  - 일정: 내 캘린더
  - 설정: 내 시간 프로필 · Calendar 연결 · 호스트 설정
  - 역할별로 화면을 나누지 않고, 누구나 호스트이자 클라이언트입니다.

## 여정 A — 처음 설정하기: Calendar → AI → 시간 프로필

1. **Calendar 연결**
   - 진행 표시 `연결 → 캘린더 선택 → 일정 가져오기 → 시간 프로필`이 지금 위치를 알려 줍니다.
   - Google 연결 버튼 옆에 "Calendar 없이 직접 설정하기"가 항상 있습니다.
   - 연결하고 돌아오면 캘린더 목록이 자동으로 뜨고, 일정 정보를 볼 수 있는 캘린더는 미리 체크돼 있습니다.
2. **마무리 버튼 두 개**
   - **저장하기**: 일정만 가져와 저장합니다.
   - **AI로 설정 시작하기**(주 버튼): 저장한 뒤 AI가 지난 8주 일정을 분류합니다(최대 1분, 진행 문구 표시).
3. **가져온 일정 확인** 창 (AI 경로에서만 나옴)
   - "분류별 / 장소별"로 묶어 보여주고, 잘못된 것은 그 자리에서 고칩니다.
   - 고친 내용이 있으면 다시 분석한 뒤 다음으로 넘어갑니다.
4. **시간 프로필 작업 화면**
   - 왼쪽: 직접 설정(근무시간 · 미팅 허용 시간 · 기본 선호 · 세 주제 확인 체크)
   - 오른쪽: AI 대화(첫 메시지가 분석 브리핑)와 주간표
   - 아래 고정 바: 저장 상태 · "주제 확인 n/3" · **최종 확인**
5. **최종 확인 → 이 설정으로 확정**
   - 세 주제를 모두 확인하고 저장이 끝나야 버튼이 켜집니다.
   - 확정하면 "프로필 설정을 완료했어요." → 내 프로필 보기 / 예약하기

수동 경로는 같은 작업 화면에서 분석 없이 진행합니다. 다시 고칠 때는 **내 시간 프로필**에서 "적용 중 · 버전 N"을 확인하고 같은 편집기로 고칩니다.

## 여정 B — 예약 받을 준비 (호스트)

- **호스트 설정**의 **제안으로 채우기**에서 캘린더나 대화로 받은 장소·양식 제안을 **추가**하거나 직접 등록합니다. 장소와 미팅 양식이 하나씩 이상 있으면 배지가 "예약 받는 중"으로 바뀝니다.
- 같은 화면의 **내 예약 링크**를 복사해 상대에게 보냅니다.
- 예약하려면 양쪽 모두 미팅 허용 시간이 있어야 합니다. 없으면 "참여자 모두 미팅 허용 시간을 설정해야 해요"로 막힙니다.

## 여정 C — 예약하기 (클라이언트)

1. **예약하기**: 연락처 카드 중 예약 가능한 사람을 고릅니다. 예약할 수 없는 사람은 점선 카드에 "예약 불가"로 표시됩니다.
2. **시작 카드** "내 기본 선호를 적용해서 새로 찾아볼까요?"
   - **새 예약 탐색 시작**을 누르거나, 이전 탐색을 이어갑니다.
3. **바로 첫 답이 나옵니다.**
   - 내가 먼저 말하지 않아도 기본 선호로 계산한 후보 최대 3개와 "기본으로 선호하시는 조건을 적용해 찾아봤어요. …" 설명이 나옵니다.
4. **조건 다듬기**
   - 말로 하기("다음 주 화·목 오후가 좋아요"), 칩 × 누르기, "기본 선호 복원·갱신"을 쓸 수 있습니다.
   - 칩마다 **기본 선호**인지 **이번 예약**인지 표시됩니다.
   - 매번 후보 최대 3개와 고른 기준이 다시 나옵니다.
5. **후보 하나 고르기** → 메시지 작성 → **요청 보내기** → "요청을 보냈어요. 내 요청 보기"
6. 그사이 일정이나 설정이 바뀌면 "후보를 새로 확인해 주세요"가 뜨고 후보 버튼이 잠깁니다.

## 여정 D — 요청 처리 (호스트)

- **받은 요청함**은 같은 시간대 요청을 한 묶음으로 보여줍니다. 묶음에는 "하나를 수락하면 나머지는 자동 거절돼요" 문구가 붙습니다.
- **수락**을 누르면 "겹치는 요청 N건은 자동 거절됩니다."를 확인한 뒤 **확인**으로 확정합니다. **거절**은 바로 처리됩니다.
- 확정되면 두 사람의 앱 캘린더에 `미팅 · 상대 이름 · 양식` 일정이 생깁니다. Google 캘린더에는 쓰지 않습니다.

## 여정 E — 확정 이후

- 클라이언트는 **내 요청**에서 상태를 보고, 대기 중인 요청은 **철회**할 수 있습니다.
- **내 캘린더**는 주 단위로 앱 일정 · 확정 미팅(초록) · 가져온 일정 · 날짜별 허용 시간을 함께 보여줍니다.
- 확정 미팅과 새 외부 일정이 겹치면 양쪽에 배지가 뜨고 "자동으로 취소되지 않아요"라고 안내합니다.

## 실패했을 때 무엇을 말해 주는가

| 상황 | 화면 반응 |
|---|---|
| 저장·요청 결과가 불분명 | "… 결과 확인" 버튼으로 같은 작업을 다시 확인 (중복 생성 없음) |
| 다른 화면에서 초안이 바뀜 | 최신 저장값을 보여주고 "내 입력으로 다시 저장 / 최신 저장값 사용" 선택 |
| AI가 말을 해석하지 못함 | 조건·설정을 그대로 두고 "해석하지 못했어요…" 안내 |
| 캘린더 새로 가져오기 실패 | "기존 일정은 그대로 유지했어요" |
| 권한이 끊김 | "권한 재연결 필요" 상태와 "Google Calendar 다시 연결" 버튼 |
