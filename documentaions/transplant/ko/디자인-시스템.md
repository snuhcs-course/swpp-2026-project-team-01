# 디자인 시스템

## 방향
CSS 첫머리에 적힌 방향은 **"시간표 노트(timetable ledger)"**입니다. 차분하고 서늘한 종이 같은 작업면에 짙은 청록 "캘린더 잉크" 하나만 강조색으로 씁니다. 시간은 항상 자릿수가 맞는 숫자로 쓰고, 시간 범위는 24시간 막대 위에 그립니다.

## 색
- **배경과 면**: 배경 #f3f5f7, 카드 흰색, 움푹한 면 #eef1f4
- **글자**: 진한 순서대로 #131a22 → #33404d → #5b6876
- **강조색**: 청록 #0b6670 하나만 씁니다. 연한 바탕은 #e3f1f2입니다.
- **상태색**: 성공 초록 #1f7a45 · 경고 주황 #9a5800 · 위험 빨강 #b4232f
- **다크 모드**: 시스템 설정을 따라 전체가 어두운 짝으로 바뀝니다. 청록은 #4fb8c1이 됩니다.

## 글꼴과 크기
- 글꼴은 Pretendard입니다. 외부 CDN 없이 앱이 직접 제공합니다.
- 한국어가 어절 중간에서 끊기지 않도록 `keep-all`을 씁니다.
- 글자 크기(px): 13 · 14 · 15(본문) · 17 · 18 · 20 · 26 · 32
- 모서리: 입력칸 8 · 카드 12 · 시트 16
- 시간·날짜·건수는 모두 자릿수가 맞는 숫자(tabular)로 씁니다.

## 기본 부품
- **버튼**: 주 / 보조 / 고스트 / 위험 / 링크, 크기 3단계(최소 높이 36·40·48)
- **배지 / 알림 상자 / 저장 상태 표시(StatusPill)**: 회색·청록·초록·주황·빨강 다섯 톤
- **카드, 페이지 머리말**(작은 제목 + 제목 + 설명 + 오른쪽 동작), **빈 상태**
- **입력칸 / 여러 줄 입력 / 선택 상자 / 체크박스 / 토글 칩**(요일 고르기)
- **진행 단계 표시(Stepper)**: 끝난 단계는 체크로 채웁니다.
- **대화 말풍선**: AI는 왼쪽에 검은 "AI" 원과 조용한 면, 내 말은 오른쪽 청록. 기다리는 중이면 점선 말풍선과 스피너를 씁니다.

## 이 제품만의 패턴
- **주간표**: 월요일부터, 24시간 막대. 위의 얇은 회색이 근무, 아래의 굵은 청록이 미팅 허용입니다.
- **요일 칩 구간 편집기**: 한 줄 = 시간 범위 + 요일 칩 + "평일에 적용" + 삭제
- **출처가 보이는 조건 칩**: 기본 선호는 회색 테두리, 이번 예약은 청록. ×로 끕니다.
- **후보 한 줄**: `10월 7일(화) 14:00 · 회사 근처 · 30분 커피챗`. 시계 아이콘이 있고, 고르면 청록 바탕에 체크가 붙습니다.
- **아래 고정 바**: 긴 편집 화면에서 저장 상태, 진행, 주 버튼을 늘 보이게 합니다.
- **오른쪽 상세 시트**: 닫으면 눌렀던 자리로 초점이 돌아갑니다.
- **그 자리에서 확인하는 삭제**: "삭제할까요? [삭제] [취소]". 팝업을 쓰지 않습니다.
- **일정 색 = 출처**: 가져온 일정은 연한 청록, 확정 미팅은 연한 초록, 앱·바쁨은 회색. 왼쪽에 3px 선을 둡니다.

## 접근성
- "본문으로 건너뛰기" 링크가 있습니다.
- 지금 위치와 오늘을 표시하고, 칩·후보에는 눌림 상태를 줍니다.
- 모든 입력에 라벨이 있고, 오류는 알림으로 읽힙니다.
- 누를 수 있는 영역은 최소 40px입니다.
- 상태를 색만으로 전달하지 않습니다(배지에 글자가 있음).

## 문구 원칙
- 해요체로 짧게 씁니다.
- 실패하면 **무엇을 지켰는지**를 말합니다. 예: "기존 일정은 그대로 유지했어요", "미저장 입력을 보존하고 있어요"
- 동작의 **범위**를 말합니다. 예: "이 앱에만 적용돼요", "Google 일정은 바뀌지 않아요", "확정하기 전까지는 현재 프로필이 바뀌지 않아요"
- 추정은 "짐작·경향·추정"이라고 부릅니다.
- 일어나지 않는 자동화를 약속하지 않습니다. 예: "자동으로 취소되지 않아요", "직접 확인해야 확정돼요"

## 이식할 때
- 대상이 Tailwind v4라면 색 토큰(`globals.css`)과 `components/ui`를 통째로 가져가면 됩니다.
- shadcn/ui를 쓰고 있다면 색을 그쪽 CSS 변수에 대응시키고, 위의 "이 제품만의 패턴"만 옮기세요.
