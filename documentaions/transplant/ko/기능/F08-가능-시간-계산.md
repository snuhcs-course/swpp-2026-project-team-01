# F08 — 가능 시간 계산 엔진 (이동시간 포함)

## 왜 이렇게 만들었나
- Calendly류는 호스트의 빈 시간만 보여줍니다. 클라이언트는 자기 일정과 **장소 사이 이동시간**을 머릿속으로 맞춰야 합니다. 여기서는 두 사람의 일정, 규칙, 이동시간을 한 번에 같은 방식으로 계산합니다. [문서]
- "가능하다"는 "그 시간에 **그 자리에 있을 수 있다**"는 뜻입니다. 허용 시간 경계에는 이동시간을 붙이지 않고, 이동은 앞뒤로 가장 가까운 **오프라인** 일정과의 거리로만 따집니다. [문서][코드]

## 계산 규칙
- 오늘부터 60일, 30분마다 시작 시각을 만듭니다. 지금부터 2시간 안의 시작은 뺍니다.
- 시작 시각 × 미팅 양식 × 장소 조합마다, 호스트와 클라이언트 **둘 다** 아래 세 조건을 통과해야 후보가 됩니다.
  1. 미팅 전체가 그 요일의 미팅 허용 구간 안에 들어간다.
  2. 어떤 바쁜 일정과도 겹치지 않는다(온라인 일정 포함).
  3. 앞뒤로 가장 가까운 오프라인 일정과의 간격이 이동시간 이상이다.
- **이동시간 표** (앞뒤 똑같이 적용)

| | 회사 근처에서 미팅 | 특정 장소에서 미팅 | 온라인 미팅 |
|---|---|---|---|
| 호스트, 직전·직후가 회사 | 30분 | 1시간 | 0 |
| 호스트, 직전·직후가 다른 곳/모름 | 1시간 | 30분 | 0 |
| 클라이언트, 직전·직후가 오프라인 | 1시간 | 1시간 | 0 |
| 같은 장소 | 0 | 0 | – |

- 온라인 일정과 종일 일정은 이동의 출발점·도착점이 되지 않습니다.
  예: 12:50까지 회사 → 12:50–13:00 온라인 → 13:00 특정 장소 미팅은 "회사 → 특정 장소"로 보아 1시간이 필요하므로 불가능합니다.
- **앞뒤 여유**: 두 사람 중 더 빠듯한 쪽의 남는 시간이고, 최대 2시간까지 셉니다. "앞뒤 여유" 선호의 점수로 쓰입니다.
- 확정된 미팅은 앱 일정이 되므로 자동으로 시간을 막습니다. 대기 중인 요청은 막지 않습니다.

## 이식할 때
가장 옮기기 쉬운 부분입니다. 입출력 없는 순수 코드이고, 이동시간 표의 모든 칸에 테스트가 있습니다. 장소 종류가 다르거나 실제 길찾기를 쓴다면 표만 바꾸고, "오프라인 일정 기준"과 "앞뒤 대칭" 원칙은 지키세요.
